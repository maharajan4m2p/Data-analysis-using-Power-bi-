# Data-analysis-using-Power-bi-
Project Overview
The dashboard provides a holistic view of a pizza business's performance, tracking key metrics from financial growth to delivery efficiency. It utilizes a variety of specialized icons and visual assets to categorize data into distinct functional areas: Sales, Growth, Operations, and Delivery.
Key Metrics & Data Points
The report is designed to monitor several critical Key Performance Indicators (KPIs):
Financial Performance: Tracks total profit and profit growth trends over time.  
Order Fulfillment: Analyzes the volume of orders and the specifics of "order delivery".  
Operational Efficiency: Measures the performance of delivery staff and overall monitor-level operational stats.  
Customer Satisfaction: Likely incorporates a "Star" rating system or feedback mechanism to evaluate service quality.  
Visual Composition
The project uses a structured layout with several high-quality graphical elements to guide the user through the data:
Thematic Icons: Icons for a pizza slice, delivery man, and a delivery bike are used to differentiate between product-specific and logistics-specific data.  
Growth Visualization: Dedicated images and charts for "profit growth" indicate a focus on longitudinal performance analysis.  
Navigation Elements: Includes functional UI components like "Home" buttons and "Down-arrows" for navigating between different report pages or drilling down into specific data hierarchies.  
Core Components
Data Models: The file contains complex data relationships (as seen in the DiagramLayout and Metadata structures) that link sales transactions to delivery logs.  
Interactive Design: The inclusion of "Registered Resources" such as buttons and theme files suggests a customized user interface designed for ease of use by business managers.
